## 0. 铁律（不可违）

1. **全量美术先行**：全部美术/UI/特效/场景/道具/动画先做完入 GitHub 仓库，验收后才写游戏代码。
2. **生成必贴漫画原页参考**（`refs/canon/`，已打通解密抓取管道）；角色=漫画原样整体移植（脸/衣/形制/头身全同）；禁凭空臆想。
3. **零特效分层**：人物/武器/场景原图无火无光无粒子；特效按角色单独生成入 `assets/fx/`。
4. **玄重尺=巨尺**（焰陨玄铁黑铁尺，非刀非剑），背负/手持双待机。
5. 找优先（CC0/可商用）→ 生成兜底；每类 4 版样稿选 1 → 批量 → **按批验收**（编号意见返工）。
6. 大件全进 GitHub 仓库/Release，本地只留进行中小文件；每代清废件。
7. **动画必须流畅连贯**，禁定格感。
8. 设置菜单 3A 级全量且**全部真实可用**。
9. 音乐：禁电子/合成器噪音；舒缓古典民乐+少量燃曲；**几十首**；每角色角色曲。

## 2. 战斗

- **键位**：LMB 普攻；RMB 闪避；**6 小技能 + 3 奥义**；Q 羁绊连携（自动触发+短演出）。
- **队伍**：1 主 + 3 助战；AI 自动走位输出 + 指令（集火/护卫/恢复）；倒地耗**斗晶**拉起。
- **闪避（BD 驱动）**：默认滑步；带斗气化翼/兽翼/三千雷动等时位移替换。
- **资源**：HP + 斗气（施放/冲刺共用，命中回气）。
- **反馈**：顿帧、震屏、伤害数字、奥义书法字砸屏、**完整 MMO 式战斗日志**。
- **地形**：每图特色机关/地形杀（流沙落石岩浆毒潭），可反制敌人。
- **掉落**：铺地面+品质光柱+自动拾取过滤。
- **死亡表现**：强烈溃散/碎裂（热血漫画感）；Boss 败北分镜。
- **精英**：手工独立设计（种类要多），非随机词缀。
- **Boss**：30 场；多阶段；三档数值缩放+地狱新招/词缀；同伴按原著剧情收服。

## 3. 成长与肉鸽

- **境界**：慢速贴近原著，一局约跨 1 大境界；突破=2-3s 特写+书法字+漫画分镜小过场。
- **局内**：技能升级三选一+坊市+Boss 掉秘籍；同技能**升星 1→5 质变 + 分支进化**。
- **局外**：**每角色独立天赋树** + 图鉴/百科（斗气大陆百科全书）。
- **死亡**：回主城结算；局外 50% 魂币+图鉴全保留；局内未撤离物资折半；章节进度保留。
- **四货币**：灵币(坊市) / 魂币(天赋) / 功勋(限定) / 斗晶(突破+拉人)。
- **难度**：普通/困难/地狱（通关上档解锁）；**诅咒词条**换额外奖励。
- **结构**：全大陆空壳；节点选路+节点内自由；**阵营倾向**（魂殿/丹塔/自由不同货与事件）；事件密集 6+/节点。
- **模式**：剧情肉鸽 + 自由探索沙盒；**NG+ 与无尽并存**；成就=本地+无尽分榜。
- **探索**：钩索/攀爬点+化翼后飞行区；传送点+城内马车；战争迷雾上图=自动标点+任务虚线（可关）；小地图全要素图标。

## 4. 角色

- **首批 15 人**：萧炎(T0 最精，含炎帝皮肤)、薰儿、美杜莎、药老、小医仙、云韵、紫研、雅妃、海波东、青鳞、凤清儿 + 可收 Boss 等。
- 独立普攻模组/技能树/被动；共享装备池 9 格（武器/衣/护腕/靴/纳戒/饰+3）；魔核镶嵌/炼化。
- 收服：核心按原著剧情节点；支线击败/事件。
- 羁绊组合技：自动触发+短演出。

## 5. 原著系统

- **异火 23 朵**全收录独特机制；吞噬→焚诀；融合配方+随机；佛怒火莲=招牌奥义。
- **技能只用原著**（小说/漫画/动画），不自创；组合=原著联动；V1 约 120→300+，标出处。
- **炼丹**：控火节奏小游戏；**城里炼药堂(高阶)+随身药鼎(野外低阶)**；固定配方+随机词条丹；炸炉；丹雷。
- **副业**：采药/挖矿/魔核/拍卖行；装备强化+纳戒升级+词条重铸。

## 6. 世界与剧情

- **20+ 章**按原著大事件；顺序解锁+章内支线岔路；对白 300-400 句/章（厚重原著文风）。
- **开场**：动画 CG+分镜「陨落的天才」，可跳过；对话自动播+快进；可跳过+回看+过场重播。
- **结局**：主线 3（好/一般/坏）+重要角色支线结局；条件解锁；**真结局需全收集**。
- **城市**：每城完整运作（独立主题建筑/色调/音乐/NPC）；NPC 完整日程+随机街头事件。
- **支线四件套**：任务板+悬赏+奇遇+收集册。

## 7. UI / UX / 设置

- **动态 UI**：普通对话共用框；重要角色专属框；Boss 战 UI；区域主题底纹。
- **动效**：面板滑入+火焰描边+印章盖章等丰富动效。
- **导航**：大地图+小地图双导航；1080p 基准+UI 缩放；格子背包 40→80/120。
- **设置 3A 全量真实可用**：显示/画质/音量×4/辅助/控制改键/语言/色弱/震屏强度/伤害数字开关等。
- **引导**：前 15 分钟剧情手把手；教学手指/高亮框。
- 本地 3 存档位；城镇旅店存档；局内死亡/撤离结算。

## 8. 音频

- BGM 几十首：场景专属（标题/城/探索×N/战斗×N/Boss/炼丹/结算/天赋树）+**每角色角色曲**；舒缓古典民乐为主+少量燃曲；CC0/可商用优先。
- SFX 分层：技能施放/命中、火焰、UI、宝箱、丹炉、突破等。
- **语音**：主要角色 AI 中文配音 ~20 句/人（喊招+登场+受击+胜利+关键剧情）+**队友闲聊彩蛋**。
