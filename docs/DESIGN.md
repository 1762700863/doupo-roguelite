## 1. 定位（已确认）

| 项 | 决定 |
|---|---|
| 类型 | 俯视角实时动作 Roguelite + 半开放大地图 + 原著系统全收录 |
| 视角 | 俯视（非横版），WASD+鼠标，预留手柄（输入层抽象） |
| 节奏 | 中速博弈：冲刺无敌帧 + 走位躲弹幕 + 技能爆发（哈迪斯式） |
| 美术 | 全面向《斗破苍穹》漫画版画风看齐 |
| 剧情 | 章节多且细、铺得长；剧情模式优先，另有自由探索 |
| 成长 | 局内随机成型 + 局外天赋树 & 图鉴（哈迪斯式） |
| 重开 | 每局流派/技能组合不同，目标几百种搭配 |
| 平台 | Windows x64 exe（Godot 4.7），zip 解压即玩，GitHub Releases 分发 |
| 范围 | V1 直接铺多区域大世界骨架（已选），十次迭代内交付完整可玩版 |

**一句话循环**：探索/战斗 → 学斗技·吞异火·炼丹 → 突破境界 → 击败区域 Boss → 解锁新章节与永久图鉴 → 下一局更自由更强。

## 2. 核心玩法循环

1. **局内**：选出发角色与开局加成 → 进入章节区域（自由走动）→ 清怪/事件/采集 → 收技能与资源 → 突破小境界 → Boss 战 → 推进或撤离结算。
2. **局外**：结算魂币 → 点天赋树 → 解锁图鉴（异火/丹方/秘籍/角色）→ 带新起点开下局。
3. **剧情模式**：固定章节主线 + 可选支线，通关推进大地图区域；自由探索模式：无剧情压力沙盒。

## 3. 战斗系统（骨架）

- 输入：WASD 移动，鼠标瞄准，LMB 普攻，RMB 闪避（无敌帧，耗斗气），1–4 主动技，R 大招/奥义，Q 队友连携。
- 资源：**HP** + **斗气**（施放与冲刺共用，攻击命中回斗气）。
- 命中反馈：顿帧、屏幕震动、伤害数字、暴击放大、技能名书法字砸屏（佛怒火莲等）。
- 敌人：包抄 AI、远程齐射、精英词缀；Boss 多阶段 + 漫画分镜败北。
- 数值哲学：允许操作型越级，但境界差提供清晰压制感。

## 4. 角色系统（骨架）

- 萧炎：最精制作，近可战远可烧混合定位，焚诀为专属成长轴。
- 伙伴：击败/剧情/好感收服；上场 1 主 + 助战（V1 规模待问卷）；AI 自动战斗+简单指令。
- 每人：独立普攻模组、独立技能树、独立被动；羁绊连携组合技（Q 触发）。
- V1 名单待定（问卷 17）。

## 5. 成长与肉鸽（骨架）

- 境界：原著大境界作章节锁，局内小突破用选牌/天材地宝。
- 局外：魂币天赋树（永久小属性、起始加成、解锁池）+ 图鉴收集。
- 随机内容池：技能掉落、坊市货、丹方残卷、事件、精英词缀、（结构待问卷 77）。
- 稀有度：按原著品阶 黄→玄→地→天（色表待定）。

## 6. 原著系统收录清单（全都要，分批做）

- **异火**：23 朵全收录，各有独特机制；吞噬→焚诀进化；融合配方 + 随机惊喜；佛怒火莲为奥义。
- **斗技/功法**：全角色原著技能一个不漏（分包：萧炎包/药老包/美杜莎包……），身法、秘法、印决、体术皆含。
- **炼丹**：可玩火候小游戏、丹方残卷、药材采集、炼药师品级、炸炉、丹雷事件（V1 简化度待问卷）。
- **炼器/副业**：纳戒强化、采药挖矿、魔核、拍卖行（按问卷取舍）。
- **势力**：云岚宗、迦南学院、黑角域、丹塔、魂殿、古族、星陨阁……映射为章节/阵营。
